[bold]Everywhere[/bold]
  Tab             Next control
  Shift+Tab       Previous control
  Arrows          Move in a list
  j / k           Move down / up in a list
  Enter           Open or activate
  Esc             Back or close
  ?               This panel
  Ctrl+P          Command palette for this screen
  F5              Refresh (also Ctrl+R)
  J               Jobs and logs
  q               Quit when no field is focused

[bold]Sessions[/bold]
  /               Search (Tab completes the last token)
  s               Select (also Space)
  S               Select all
  E               Export a session bundle
  x               Delete (press twice)

%%catalog-query%%

[bold]Browser[/bold]
  [ ]  1-4        Timeline, Summary, Diff, Notes
  h / l / Left / Right    Previous / next turn on the Timeline
  j / k           Previous / next Timeline event, or previous / next note
  v               Filter (Subagents, Background, Workflows)
  Enter           Open a Timeline event or child; edit the focused note
  N               New note
  y               Copy the selection or the focused / primary pane body
  Ctrl+Shift+C    Same as y
  s               Open the share link when the session has one
  E               Export a session bundle
  x               Delete (press twice)

[bold]Runner[/bold]
  Ctrl+Enter      Launch
  Ctrl+S          Save recipe
  T               Export this form as task YAML
  [ ]  1-3        Recipe, Runtime, Extras

[bold]Recipes[/bold]
  Enter           Open in the runner
  l               Launch
  L               Launch selected
  s               Select
  n               New
  x               Delete
  T               Export as task YAML

[bold]Personas[/bold]
  Enter           Edit
  n               New
  x               Delete
  Ctrl+S          Save in the editor

[bold]Pickers[/bold]
  s               Select
  Ctrl+S          Apply the selection
  Esc             Cancel

The footer lists primary keys. The palette lists the rest.

Desktop HUD shares ? / Esc / / / y / j k / h l (Timeline turns) / n e
(awaiting) / N with this TUI. HUD panes are Tab and Ctrl+1-5; [ ] also
scope Timeline turns (all / next).
A keys.toml remap applies on both surfaces. An overlay may set one
leader key, then one letter (leader+X). Esc or timeout cancels.
Copy examples/keys/colemak.toml to ~/.groket/keys.toml for Colemak
home-row n/e nav with follow-up and Done behind semicolon.
