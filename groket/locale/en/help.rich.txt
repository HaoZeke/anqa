[bold]Keys[/bold]

Tab / Shift+Tab    move between controls
Arrows / Home / End  move inside lists
Enter / Space      open or activate
Esc                back or close
?                  this help
Ctrl+P             command palette (everything for this screen)
F5 / Ctrl+R        refresh
j                  jobs and logs
q                  quit (any screen; types into focused Input/TextArea)

[bold]Session list[/bold]
Enter open · / search · r new run · C recipes · P personas
s select · S select all · x delete (twice)
R re-run recipe · f fork ended session (new multi-turn)
Ctrl+S save row as a recipe
E              export highlighted/selected session tarball
I              import host session (fuzzy list under ~/.grok/sessions)

[bold]Session browser[/bold]
[ ] or 1–5     panes (timeline, summary, diff, findings, report)
v              timeline view filter
f              flag event
N              new operator note (turn-linked; schema from ~/.groket/notes_schema.toml)
O              edit / delete operator note (palette; Delete in modal)
n              follow-up prompt · e done (multi-turn)
x              delete this session (twice)
s              open share link
y              copy selection, focused report section, Report tab, or detail pane
Ctrl+Shift+C   same as y
Ctrl+C         copy mouse selection when text is selected (otherwise quit hint)
E              export session tarball (~/.groket/reports; embeds grok-trace.tar.gz + notes/)

[dim]Partial copy: drag to highlight text in the detail pane or a Report section,
then y / Ctrl+C / Ctrl+Shift+C. With no highlight: on Report, y yanks all
visible sections (or the focused section); on Timeline, y yanks the detail
body (OSC 52 clipboard). OS “highlight to copy” does not work while the TUI
owns the mouse.[/dim]

[bold]Runner[/bold]
Ctrl+Enter (or Ctrl+J) launch · Ctrl+S save recipe · T export as task YAML · [ ] panes
Repository URL clones into runs/checkouts/; [bold]Local path[/bold] bind-mounts that host directory as /workspace (live edits, single model).
YOLO checkbox → ``grok --yolo`` (default is ``--always-approve`` only).

[bold]Recipes & personas[/bold]
Enter open · l launch · s select · n new · x delete · T export as task YAML
Editor: [ ] panes · Ctrl+S save

[bold]Pickers[/bold]
s select · Ctrl+S done · Esc cancel

[dim]Footer shows primary keys. Ctrl+P lists the rest.[/dim]
